# Yerki downloads

Public beta installers for Yerki. No GitHub account is needed to download.

## Mac

[Download Yerki Beta 0.1.30 for Mac](https://github.com/DavidNorris76/yerki-downloads/releases/download/v0.1.30-mac-beta/Yerki-Beta-0.1.30-mac-arm64.dmg)

Requires Apple Silicon and macOS 14.2 or later. Open the DMG, drag Yerki Beta to Applications, then launch it and follow the sign-in and recording-permission prompts.

Developer ID signed and Apple notarised. This beta is a test candidate; physical microphone/system audio and Zoom/Teams validation are still pending.
